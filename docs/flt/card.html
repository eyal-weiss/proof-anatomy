Method and limits

  • Counts are from the source text: comments and import lines removed; theorems = theorem and lemma declarations; definitions = def and abbrev. Mathlib's counts come from its published declaration table as downloaded on 2026-11-21 (246,464 theorems, 44,906 definitions, 8,557 files); the two are counted differently, so ratios are approximate.
  • Areas: each file's lines are split among Mathlib's top-level folders by the Mathlib names it uses, each name weighted by log(1 + uses) and discounted by how many of the project's files use it (1 + log((1 + files) / (1 + files using it)), where files counts the files that use any name from the table). Files with no Mathlib name (0.04% of lines) take the mix of the files that import them.
  • Borrowed or new: each name is looked up in Lean's order, line by line (local variables, then the current namespace and its parents, then the name as written, then opened namespaces); the first match decides whether it is the project's own, Mathlib's, or from Lean core and the other libraries Mathlib uses. Local variables and names Lean generates are not counted.
  • Famous theorems: only declarations that Mathlib's own lists name (theorems, and the definitions or instances some entries point to), and only when the code names them; a theorem used through a tactic is missed.
  • Map: the author's folders at the first level with at least 8 folders holding 1% of the lines each; a curve joins two folders when files in one import files in the other.
  • Text only: no build, so no check that the proof is correct, and no exact dependency trace. The project pins Mathlib 56a005855e; the table is today's, so renamed names may not resolve (83.7% of qualified names were traced to the table).
